# 我们的音乐重合度

粘贴两个歌单链接，算出**你们共同喜欢多少首歌**，把重复的歌列出来 ——
还能**直接按顺序播放**这批共同歌曲。

支持 **网易云音乐 / QQ 音乐 / 酷狗音乐**，而且**三家之间可以混着比**
（比如「我的网易云喜欢」对「你的 QQ 音乐歌单」）。

本地小工具，**零第三方依赖**，只在你自己的电脑上运行，不经过任何第三方服务器。

## 它能做什么

- **粘贴链接就出结果**：三家的歌单页面地址、手机分享链接、纯歌单 ID 都认，
  也支持粘**网易云用户主页链接**（会自动去找 TA 的「我喜欢的音乐」）
- **跨平台对比**：两边的歌单可以来自不同平台，靠「歌名 + 歌手」对上
- **显示两个人的昵称和头像**，以及各自歌单的名字和歌曲数
- **共同歌曲带封面**，一眼能认出是哪张专辑
- **每首歌标出它来自哪个平台**，跨平台时还会写出「另一边是哪首歌」
- **四种呈现方式**：列表 / 小图标 / 中图标 / 大图标（像 Windows 文件夹的「查看」那样切换，会记住你的选择）
- **算完自动开播**：对比一完成就自己从第一首能放的歌开始按顺序播，带进度条（可拖动）、上一首 / 下一首 / 暂停 / 音量
- **页面和歌曲渐进出现**，不是一下全砸出来
- **结果摘要就一张卡**：两个人、共同数字、重合度、口径都在同一块里，不重复堆数字
- **该说的限制会主动说**：读不全、口径偏松、被截断，都会在结果上方摆一条提醒
- **搜索过滤 / 复制列表 / 导出 CSV**（CSV 带来源平台、能不能播、原站链接）

## 快速开始

需要 [Node.js](https://nodejs.org/)（18 以上，建议 LTS）。

**Windows**：双击 `启动.bat`，浏览器会自动打开。

**其他系统 / 手动启动**：

```bash
node server.mjs            # 默认 http://127.0.0.1:8787
node server.mjs 9000       # 换端口
```

然后打开 <http://127.0.0.1:8787>，把两边的歌单链接粘进去，点「开始对比」。

## 三个平台各自能做什么

| 平台 | 读歌单 | 听歌 | 备注 |
|---|---|---|---|
| **网易云音乐** | 全量 | ✅ | 支持整份「我喜欢的音乐」；VIP 曲要填登录凭证 |
| **QQ 音乐** | 全量 | ✅ | 需要 `y.qq.com` 的歌单页地址；付费曲拿不到地址 |
| **酷狗音乐** | **只读得到前 30 首** | ❌ | 公开页面就只放 30 首，且播放地址要浏览器行为指纹 |

酷狗那两条是它的接口限制，不是这里偷懒：工具会**如实标出来**（结果上方一条提醒 +
每首歌标「无法试听」+ 「按顺序播放全部」置灰并说明原因），不会假装能播。

## ⚠️ 几条需要知道的限制

**1. 歌单必须是「公开」的。**

平台不允许未登录查看私密歌单。如果对方的「我喜欢的音乐」设成了私密，程序读不到，
页面会明确告诉你「读不到歌单列表」，而不是假装算出个 0。

让对方改一下（30 秒）：网易云 → 我的音乐 → 我喜欢的音乐 → 「···」→ 编辑 → 关掉「私密歌单」。

**2. 有的歌放不出来，这是平台的限制，不是程序的毛病。**

- 网易云 / QQ 的 **VIP、付费、无版权**曲目不向未登录用户提供音频。这类歌在列表里会标上
  「VIP 专享」或「受限」，连播时会自动跳过，不会卡住。
- 如果你自己开了会员，把浏览器里的登录凭证填进页面下方「进阶」区，就能连会员曲一起播。

> 实测样本：某两个公开歌单的 88 首共同歌曲里，26 首可以直接播放 —— 比例因歌单而异，
> 越偏冷门/独立音乐的喜欢列表，能直接播的比例通常越高。
>
> 自动播放会**从第一首能放的歌开始**，中途遇到不能放的直接跳过，不会卡住。

**3. 跨平台的数字天生比同平台「宽」。**

两边不是同一家时，歌曲 ID 体系不同，只能靠「歌名 + 歌手」匹配，比同平台的 ID 精确匹配宽松。
这种情况下结果上方会有一条提醒说明。所以**跨平台的数字不要直接和同平台的数字比**。

## 匹配口径

口径由「两边是不是同一家平台」自动决定：

| 场景 | 判断依据 | 说明 |
|---|---|---|
| **同一平台**（默认口径） | 歌曲 ID 完全相同 | 最准，不会虚高 |
| 同一平台的「疑似同版本」 | 歌名 + 歌手完全相同 | 单独列在「疑似同一首歌（不同版本）」里，不计入大数字 |
| **跨平台** | 歌名 + 歌手完全相同 | 只能如此，结果上方会提示口径偏松 |

音频版本不同（原版 / Acoustic / Live）**不会被算成同一首** —— 录音不一样，算进去会让数字虚高。
**宁可少算，不误算。**

## 实测

**同平台**（两个真实的网易云公开歌单，2206 首 × 620 首）：

- 共同歌曲 **88 首**，重合度 14.2%，用时约 0.5 秒
- 这个数字用**另一套独立脚本重算过**，结果一致
- 另有 8 首「同名不同版本」单独列出（88 + 8 = 96）

**跨平台**（同一份网易云歌单 × 某 QQ 音乐歌单 137 首）：共同 11 首，用时约 1.8 秒。

## 技术说明

服务端只用 Node 内置模块，**不需要 `npm install`**。用到的都是各家公开接口：

| 平台 | 接口 | 用途 |
|---|---|---|
| 网易云 | `/api/v6/playlist/detail?id=X&n=1` | 歌单元数据 + **全量** `trackIds` + 创建者昵称/头像 |
| 网易云 | `/api/user/playlist?uid=X` | 列出用户歌单，按 `specialType=5` 定位「我喜欢的音乐」 |
| 网易云 | `/api/v3/song/detail?c=[…]` | 批量取歌名 / 歌手 / 专辑 / 封面，200 首一批 |
| 网易云 | `/api/song/enhance/player/url/v1` | 取播放地址（VIP 曲返回 `code: -110`） |
| QQ 音乐 | `c.y.qq.com/qzone/fcg-bin/fcg_ucc_getcdinfo_byids_cp.fcg` | 歌单详情，**带 `song_begin` / `song_num` 翻页**拿全量 |
| QQ 音乐 | `u.y.qq.com/cgi-bin/musicu.fcg` (`vkey.GetVkeyServer`) | 取播放地址（付费曲 `result: 104003`，`purl` 为空） |
| 酷狗 | `www.kugou.com/yy/special/single/{id}.html` | 歌单页内联的 `var data=[…]`，**只有 30 首** |

本工具自己对外提供的接口：

| 接口 | 用途 |
|---|---|
| `GET /api/platforms` | 平台清单与输入提示（前端启动时拉一次） |
| `POST /api/compare` | 对比两个歌单 |
| `POST /api/audio-url` | 批量查询哪些歌能播（按平台分组，用于在列表上标注） |
| `POST /api/cookie` | 提交登录凭证，**只写内存** |
| `GET /api/audio?platform=&sid=` | 音频流代理，**透传 Range**，进度条才能拖动 |

音频为什么要走本地代理：各家的音频地址都有防盗链和跨域限制，直接给 `<audio>` 用会失败；
代理还顺便解决了不暴露登录凭证的问题。

## 发给不懂命令行的人用

```bash
node _dev/build-portable.mjs          # 打包，产物在 dist/
```

打出来的 `dist/音乐重合度-便携版.zip`（约 **33MB**）解压后**双击「启动.bat」就能用**：

- 里面自带一份便携版 Node 运行时（`bin/node.exe`），**朋友什么都不用装**
- 启动器会自动打开浏览器；**关掉黑窗口就停止服务**
- 端口被占用时会自己换到 8788 再试一次，并告诉用户为什么
- 附 `打开音乐重合度.lnk`（带名字的入口）和 `先看我.txt`（30 秒说明）

参数：`--no-runtime` 只打程序（给已装 Node 的人，几十 KB）；`--no-zip` 只铺文件夹不压缩。
`dist/` 不进版本库——它是构建产物，随时能重新打出来。

**为什么不打成一个单文件 exe**：那要用 Node 的 SEA 把代码和前端塞进可执行文件，还得处理
Windows 清单（否则可能弹 UAC），改一行代码就得重新构建，出问题也没法让朋友自己看是哪个文件。
现在这样零构建依赖、改完直接生效。88MB 的运行时压完只剩 33MB，正常分享没问题。

直连即可。网络需要代理时：

```bash
set MUSIC_PROXY=127.0.0.1:7890    # cmd
$env:MUSIC_PROXY="127.0.0.1:7890" # PowerShell
export MUSIC_PROXY=127.0.0.1:7890 # macOS / Linux
node server.mjs
```

### 改完代码怎么验

先起服务（比如 `node server.mjs 8799`），再开一个窗口跑：

```
node _dev/api-check.mjs 8799    # 接口层，56 项断言，几秒跑完
set BASE=http://127.0.0.1:8799  # PowerShell: $env:BASE="http://127.0.0.1:8799"
node "_dev/多平台自检.mjs"       # 界面层，47 项：三平台 / 跨平台 / 酷狗降级 / 播放器
node "_dev/新界面自检.mjs"       # 界面回归，43 项：四视图 / 播放控制 / 搜索过滤
```

三道全绿是提交前的底线。界面层的两个脚本用系统自带的 Edge 无头模式真实点一遍，
并把每一步的截图写到 `_dev/`（截图里含真实歌单名与头像，所以 `_dev/shot-*.png`
和自检记录都在 `.gitignore` 里，不上传）。

## 隐私

- 请求直接发往各平台自己的域名，本工具没有任何后端服务器
- 页面下方的可选凭证只用于请求对应平台，**不写入任何文件**；它存在内存里，关掉服务就没了
- 代码不做任何数据上报
