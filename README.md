# 我们的音乐重合度

粘贴两个人的网易云音乐「我喜欢的音乐」歌单链接，算出**你们共同喜欢多少首歌**，
把重复的歌列出来 —— 还能**直接按顺序播放**这批共同歌曲。

本地小工具，**零第三方依赖**，只在你自己的电脑上运行，不经过任何第三方服务器。

## 它能做什么

- **粘贴链接就出结果**：支持歌单页面地址（含 `#` 的那种）、手机分享链接、纯歌单 ID，
  也支持直接粘**对方的用户主页链接**（会自动去找 TA 的「我喜欢的音乐」）
- **显示两个人的昵称和头像**，以及各自歌单的名字和歌曲数
- **共同歌曲带封面**，一眼能认出是哪张专辑
- **四种呈现方式**：列表 / 小图标 / 中图标 / 大图标（像 Windows 文件夹的「查看」那样切换，会记住你的选择）
- **算完自动开播**：对比一完成就自己从第一首能放的歌开始按顺序播，带进度条（可拖动）、上一首 / 下一首 / 暂停 / 音量
- **页面和歌曲渐进出现**，不是一下全砸出来
- **结果摘要就一张卡**：两个人、共同数字、重合度、口径都在同一块里，不重复堆数字
- **两种匹配口径**：默认按歌曲 ID 精确匹配；可切换「同名同歌手也算」
- **搜索过滤 / 复制列表 / 导出 CSV**（CSV 里会标注每首歌能不能播）

## 快速开始

需要 [Node.js](https://nodejs.org/)（18 以上，建议 LTS）。

**Windows**：双击 `启动.bat`，浏览器会自动打开。

**其他系统 / 手动启动**：

```bash
node server.mjs            # 默认 http://127.0.0.1:8787
node server.mjs 9000       # 换端口
```

然后打开 <http://127.0.0.1:8787>，把两边的歌单链接粘进去，点「开始对比」。

## ⚠️ 两条需要知道的限制

**1. 歌单必须是「公开」的。**

网易云不允许未登录查看私密歌单。如果对方的「我喜欢的音乐」设成了私密，程序读不到，
页面会明确告诉你「读不到歌单列表」，而不是假装算出个 0。

让对方改一下（30 秒）：网易云 → 我的音乐 → 我喜欢的音乐 → 「···」→ 编辑 → 关掉「私密歌单」。

**2. 有的歌放不出来，这是网易云的限制，不是程序的毛病。**

网易云对 **VIP 专享曲目**不向未登录用户提供音频。这类歌在列表里会标上「VIP 专享」，
连播时会自动跳过，不会卡住。

如果你自己开了网易云会员，把浏览器里的登录凭证填进页面下方「读不到歌单 / 有的歌放不出来？」
的输入框，就能连会员曲一起播。

> 实测样本：某两个公开歌单的 88 首共同歌曲里，26 首可以直接播放 —— 比例因歌单而异，
> 越偏冷门/独立音乐的喜欢列表，能直接播的比例通常越高。
>
> 自动播放会**从第一首能放的歌开始**，中途遇到不能放的直接跳过，不会卡住。

## 两种口径的差别

| 口径 | 判断依据 | 说明 |
|---|---|---|
| **默认（严格）** | 歌曲 ID 完全相同 | 最准，不会虚高 |
| 宽松 | 歌名 + 歌手完全相同 | 会多算出「同一首歌收录在不同专辑」的情况，结果单独列出 |

音频版本不同（原版 / Acoustic / Live）**不会被算成同一首** —— 录音不一样，算进去会让数字虚高。
**宁可少算，不误算。**

## 实测

拿两个真实的公开歌单跑过（2206 首 × 620 首）：

- 共同歌曲 **88 首**，重合度 14.2%，用时约 0.5 秒
- 这个数字用**另一套独立脚本重算过**，结果一致
- 宽松口径下为 96 首（88 首 ID 相同 + 8 首同名不同版本）

## 技术说明

服务端只用 Node 内置模块，**不需要 `npm install`**。用到的网易云公开接口：

| 接口 | 用途 |
|---|---|
| `/api/v6/playlist/detail?id=X&n=1` | 歌单元数据 + **全量** `trackIds` + 创建者昵称/头像（`n` 只控制 `tracks` 数组长度） |
| `/api/user/playlist?uid=X` | 列出用户歌单，按 `specialType=5` 定位「我喜欢的音乐」 |
| `/api/v3/song/detail?c=[{"id":1},…]` | 批量取歌名 / 歌手 / 专辑 / 封面，200 首一批 |
| `/api/song/enhance/player/url/v1` | 取播放地址（未登录只有免费曲返回真实地址，VIP 曲返回 `code: -110`） |

本工具自己对外提供的接口：

| 接口 | 用途 |
|---|---|
| `POST /api/compare` | 对比两个歌单 |
| `POST /api/audio-url` | 批量查询哪些歌能播（用于在列表上标注） |
| `GET /api/audio?id=X` | 音频流代理，**透传 Range**，进度条才能拖动 |

音频为什么要走本地代理：网易的音频地址有防盗链和跨域限制，直接给 `<audio>` 用会失败；
代理还顺便解决了不暴露 `MUSIC_U` 凭证的问题。

直连即可，只需带 `Referer: https://music.163.com/`。网络需要代理时：

```bash
set MUSIC_PROXY=127.0.0.1:7890    # Windows
export MUSIC_PROXY=127.0.0.1:7890 # macOS / Linux
node server.mjs
```

## 隐私

- 所有请求直接发往 `music.163.com`，本工具没有任何后端服务器
- 页面下方的可选 Cookie 只用于请求网易云，**不写入任何文件**；它存在内存里，关掉服务就没了
- 代码不做任何数据上报
