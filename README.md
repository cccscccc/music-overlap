# 我们的音乐重合度

粘贴两个人的网易云音乐「我喜欢的音乐」歌单链接，算出**你们共同喜欢多少首歌**，并把重复的歌单列出来。

本地小工具，**零第三方依赖**，只在你自己的电脑上运行 —— 不经过任何第三方服务器。

## 它能做什么

- **粘贴链接就出结果**：支持歌单页面地址（含 `#` 的那种）、手机分享链接、纯歌单 ID，
  也支持直接粘**对方的用户主页链接**（会自动去找 TA 的「我喜欢的音乐」）
- **给出共同歌曲数量 + 重合度**（占较小歌单的比例 / 交集÷并集）
- **列出重复歌曲明细**：歌名、歌手、专辑、时长，可点击跳回网易云
- **两种匹配口径**：默认按歌曲 ID 精确匹配；可切换「同名同歌手也算」
- **搜索过滤 / 复制列表 / 导出 CSV**

## 快速开始

需要 [Node.js](https://nodejs.org/)（18 以上，建议 LTS）。

**Windows**：双击 `启动.bat`，浏览器会自动打开。

**其他系统 / 手动启动**：

```bash
node server.mjs            # 默认 http://127.0.0.1:8787
node server.mjs 9000       # 换端口
```

然后打开 <http://127.0.0.1:8787>，把两边的歌单链接粘进去，点「开始对比」。

## ⚠️ 最重要的一条限制

**歌单必须是「公开」的。**

网易云不允许未登录查看私密歌单。如果对方的「我喜欢的音乐」设成了私密，程序读不到，
页面会明确告诉你「读不到歌单列表」，而不是假装算出个 0。

让对方改一下（30 秒）：网易云 → 我的音乐 → 我喜欢的音乐 → 「···」→ 编辑 → 关掉「私密歌单」。

## 两种口径的差别

| 口径 | 判断依据 | 说明 |
|---|---|---|
| **默认（严格）** | 歌曲 ID 完全相同 | 最准，不会虚高 |
| 宽松 | 歌名 + 歌手完全相同 | 会多算出「同一首歌收录在不同专辑」的情况，结果单独列出 |

音频版本不同（原版 / Acoustic / Live）**不会被算成同一首** —— 录音不一样，算进去会让数字虚高。
**宁可少算，不误算。**

## 实测

拿两个真实的公开歌单跑过（2206 首 × 620 首）：

- 共同歌曲 **88 首**，重合度 14.19%，用时约 0.5 秒
- 这个数字用**另一套独立脚本重算过**，结果一致
- 宽松口径下为 96 首（88 首 ID 相同 + 8 首同名不同版本）

## 技术说明

服务端只用 Node 内置模块，**不需要 `npm install`**。用到的网易云公开接口：

| 接口 | 用途 |
|---|---|
| `/api/v6/playlist/detail?id=X&n=1` | 取歌单元数据 + **全量** `trackIds`（`n` 只控制 `tracks` 数组长度） |
| `/api/user/playlist?uid=X` | 列出用户歌单，按 `specialType=5` 定位「我喜欢的音乐」 |
| `/api/v3/song/detail?c=[{"id":1},…]` | 批量取歌名 / 歌手 / 专辑，200 首一批 |

直连即可，只需带 `Referer: https://music.163.com/`。网络需要代理时：

```bash
set MUSIC_PROXY=127.0.0.1:7890    # Windows
export MUSIC_PROXY=127.0.0.1:7890 # macOS / Linux
node server.mjs
```

## 隐私

- 所有请求直接发往 `music.163.com`，本工具没有任何后端服务器
- 页面下方的可选 Cookie 只用于请求网易云，**不写入任何文件**
- 代码不做任何数据上报
