# android/ — 手机 App（极简壳）

这是一个**很薄的安卓壳**：它自己不算歌单、不存数据，只做三件事 ——
找到你电脑上那个服务、把它的页面当 App 打开、连不上时让你手填地址。

## 为什么是「壳」而不是一个自带运行时的独立 App

这个工具能放歌，靠的是**电脑那边的 Node 服务替浏览器补 `Referer`**：
三家的播放地址都要这个头，而浏览器（包括 WebView）里的 JS 设不了它 —— 这是浏览器的安全规定，绕不过去。

所以有两条路：

| 做法 | 结果 |
| --- | --- |
| **壳 + 电脑上的服务**（本目录） | 体积 ~200KB，页面和电脑端同一份，改界面两边同时生效。代价：用的时候电脑要开着 |
| 把 Node 运行时也打进 apk | 体积 60MB+，还得处理「Android 10+ 不让执行私有目录里的二进制」、后台保活、各家 ROM 的省电策略。属于另一个工程 |

这一版选了前者：**手机上体验的是「App 的样子」，能力仍然来自电脑**。

## 怎么用

1. 电脑上双击 `手机访问.bat`（或 `node server.mjs --lan`），它会打印一个地址。
2. 手机和电脑连同一个 WiFi，打开这个 App，它会自动扫局域网里的 8787 端口并连上。
3. 扫不到（比如路由器开了客户端隔离），就在 App 里手填那个地址。

App 会记住上次连通的地址，下次直接进。长按页面可以换地址。

## 怎么构建

```bash
# 一次性准备（大约 400MB 下载）
#   JDK 17 解到 android/.jdk
#   Android cmdline-tools 解到 android/.sdk
#   sdkmanager "platforms;android-34" "build-tools;34.0.0"

set ANDROID_SDK_ROOT=%CD%\android\.sdk
set JAVA_HOME=%CD%\android\.jdk
node android/build.mjs
# → dist/music-overlap-android.apk
```

构建脚本不用 Gradle：这个 App 只有 1 个 Activity、0 个第三方依赖、0 个 XML 布局，
直接调 `aapt2` / `javac` / `d8` / `zipalign` / `apksigner` 五步就够了，出错也能看清是哪一步。

签名用的是仓库里的 `debug.keystore`（口令 `android`）。**这是自用签名，不是上架签名**：
换一台机器重新构建会得到不同的证书，覆盖安装会失败，需要先卸载旧的。

## 没能验证的地方

- **没有在真机上跑过**：这台开发机没有安卓设备，虚拟化在 BIOS 里是关的所以也开不了模拟器。
  能验的只有「APK 能构建、签名有效、清单和资源都对」，跑起来顺不顺只能靠人试。
- 局域网扫描默认按 /24（1–254）并行试，6 秒一轮；企业网络里网段更大、或者开了 AP 隔离时，
  自动发现会失败——那就手填地址，功能一样。
